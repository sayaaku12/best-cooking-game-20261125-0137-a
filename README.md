Ember & Thyme — Rush Hour Kitchen: an original timed cooking game. Take orders from the order board, grab ingredients from the pantry, chop vegetables on the board, grill patties before they burn, assemble each dish on the counter and serve it at the window before the ticket walks out. Five recipes, combo tips, three hearts, one 2½-minute shift — all in static files, playable offline in a desktop browser with keyboard and mouse.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in a desktop browser.
